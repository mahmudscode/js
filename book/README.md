# JavaScript: End to End
### A Complete Guide from First Line to Production

This book takes you from "what is a variable" all the way to building,
testing, and shipping real JavaScript applications in the browser and on
Node.js. Every chapter pairs explanation with runnable code. The matching
code for chapter `NN-topic.md` lives in `examples/NN-topic.js` (or a
subfolder for multi-file examples) — open it, run it with `node`, and
experiment.

## How to use this book

```bash
node examples/03-variables-and-data-types.js
```

Every example file runs standalone with plain Node.js (no build step, no
dependencies) unless a chapter says otherwise (DOM chapters need a browser
console instead).
